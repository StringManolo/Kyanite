# Глоссарий

Краткие объяснения технических слов, которые встречаются в документации Kyanite.

| Термин | Значение |
| --- | --- |
| **Linux** | Семейство свободных операционных систем. Kyanite — небольшая Linux-система. |
| **Ядро (kernel)** | Центральная часть операционной системы. Она взаимодействует с оборудованием. У Kyanite пока нет собственного ядра; она использует ядро устройства, на котором запущена (*хоста*). |
| **Корневая файловая система (rootfs)** | Все файлы, из которых состоит Linux-система: программы, настройки и папки. Kyanite распространяется в виде rootfs. |
| **Терминал** | Окно, в котором вы вводите команды. |
| **Оболочка (shell)** | Программа внутри терминала, которая читает ваши команды и выполняет их. Kyanite использует Brush. |
| **Команда** | Инструкция, которую вы вводите в оболочке, например `ls` для просмотра списка файлов. |
| **Пакет** | Программа (или библиотека), упакованная для удобной установки. |
| **Менеджер пакетов** | Инструмент, который устанавливает, обновляет и удаляет пакеты. В Kyanite это `kpkg`. |
| **Репозиторий** | Онлайн-коллекция пакетов. Kyanite использует репозитории Debian. |
| **Debian** | Известный дистрибутив Linux с очень большой коллекцией пакетов. |
| **Init** | Первая программа, которую запускает система. Она запускает оболочку и поддерживает работу системы. |
| **PRoot** | Инструмент, который запускает Linux-систему внутри папки без специальных прав. Сейчас Kyanite работает именно так. |
| **Rust** | Язык программирования, разработанный для предотвращения многих ошибок работы с памятью — частого источника проблем безопасности. |
| **musl и glibc** | Две библиотеки языка C, необходимые программам для работы. Собственные инструменты Kyanite используют musl; пакеты Debian используют glibc. Обе включены в систему. |
| **Архитектура** | Тип процессора. `aarch64` (ARM64) распространена в телефонах; `x86_64` (AMD64) — в большинстве ПК. |
| **Контрольная сумма (SHA256)** | Короткий «отпечаток» файла. Если файл изменится, отпечаток тоже изменится, поэтому так можно обнаружить повреждённую загрузку. |
| **Подпись (Ed25519)** | Способ доказать, что файл опубликован его настоящим автором. |
| **APK** | Формат файлов приложений Android. |
| **MOTD** | «Сообщение дня» — текст, который показывается при входе в систему. |
| **Хук (hook)** | Небольшое правило Kyanite, которое настраивает пакет после установки. См. [Хуки пакетов](package-hooks.md). |
| **База (base)** | Предустановленная часть Kyanite; обновляется через релизы Kyanite, а не как обычные пакеты. |

Вернуться к [оглавлению документации](../../README.ru.md#документация).
