# Использование

В этом руководстве рассказывается об интерактивной оболочке, входящей в Kyanite, и основных способах её настройки.

## Запуск сеанса

`/bin/sh` в Kyanite указывает на `/sbin/init`. Init настраивает терминал и запускает Brush как интерактивную login-оболочку.

Когда оболочка завершается, завершается и init, и сеанс заканчивается.

## Файлы конфигурации оболочки

| Путь | Назначение |
| --- | --- |
| `/etc/profile` | Профиль входа; выводит MOTD и загружает `~/.bashrc` |
| `/root/.bashrc` | Приглашение, настройки истории, псевдонимы и вспомогательные функции |
| `/etc/update-motd.d/` | Скрипты, формирующие сообщение дня |
| `/etc/motd` | Необязательный статический текст, выводимый после скриптов MOTD |
| `/etc/kyanite/logo.txt` | ASCII-логотип, который показывает скрипт MOTD с логотипом |
| `/etc/os-release` | Название дистрибутива и версия сборки |

Файлы по умолчанию хранятся в каталоге [`rootfs-overlay/`](../../rootfs-overlay/) репозитория.

## Настройка сообщения дня

Скрипты MOTD запускаются из `/etc/update-motd.d/` в порядке имён файлов.

Чтобы отключить скрипт, сохранив файл:

```sh
chmod -x /etc/update-motd.d/00-logo
```

Чтобы добавить статическое сообщение:

```sh
printf '%s\n' 'Welcome to Kyanite' > /etc/motd
```

Чтобы отключить MOTD при вашем входе:

```sh
touch ~/.hushlogin
```

Цвета отключаются, если задана переменная `NO_COLOR` или `TERM` равна `dumb`.

Скрипты MOTD запускаются через `/bin/brush`, поэтому им не нужна строка shebang `#!/bin/sh`.

## Настройка логотипа

Замените `/etc/kyanite/logo.txt` своим заранее раскрашенным текстом.

Например, если установлен `chafa`:

```sh
chafa --size=36x --colors=256 logo.png > /etc/kyanite/logo.txt
```

## Псевдонимы и вспомогательные команды

Файл `.bashrc` по умолчанию содержит приглашение, настройки истории, псевдонимы и вспомогательные функции, такие как `extract` и `gacp`.

Некоторые команды, которые используют эти функции, устанавливаются отдельно. Например:

```sh
kpkg add tar git curl unzip
```

Об установке и управлении пакетами см. [руководство по kpkg](kpkg.md).

## Окружение

Обычно загрузчик задаёт переменные окружения, такие как `HOME`, `USER`, `LOGNAME`, `TERM`, `LANG` и `PATH`. Точные значения могут различаться в зависимости от терминала и интеграции с хостом.
