# 术语表

对 Kyanite 文档中出现的技术词汇的简短解释。

| 术语 | 含义 |
| --- | --- |
| **Linux** | 一类自由的操作系统。Kyanite 是一个小型 Linux 系统。 |
| **内核（Kernel）** | 操作系统的核心，负责与硬件打交道。Kyanite 目前还没有自己的内核，它使用所运行设备（即*宿主*）的内核。 |
| **根文件系统（rootfs）** | 构成一个 Linux 系统的全部文件：程序、设置和文件夹。Kyanite 以 rootfs 的形式分发。 |
| **终端（Terminal）** | 你输入命令的窗口。 |
| **Shell** | 终端中读取并执行你所输入命令的程序。Kyanite 使用 Brush。 |
| **命令（Command）** | 你在 shell 中输入的指令，例如用 `ls` 列出文件。 |
| **软件包（Package）** | 为方便安装而打包的程序（或库）。 |
| **包管理器（Package manager）** | 用来安装、更新和卸载软件包的工具。在 Kyanite 中是 `kpkg`。 |
| **软件源（Repository）** | 在线的软件包集合。Kyanite 使用 Debian 的软件源。 |
| **Debian** | 一个知名的 Linux 发行版，拥有非常庞大的软件包集合。 |
| **Init** | 系统启动的第一个程序。它负责启动 shell 并维持系统运行。 |
| **PRoot** | 一种无需特殊权限、就能在文件夹中运行 Linux 系统的工具。Kyanite 目前就是这样运行的。 |
| **Rust** | 一种编程语言，旨在防止许多与内存有关的错误，而这类错误是安全问题的常见来源。 |
| **musl 和 glibc** | 程序运行所需的两种 C 库。Kyanite 自带的工具使用 musl；Debian 软件包使用 glibc。两者都已包含在内。 |
| **架构（Architecture）** | 处理器的类型。`aarch64` (ARM64) 常见于手机；`x86_64` (AMD64) 常见于大多数电脑。 |
| **校验和（SHA256）** | 文件的简短“指纹”。文件一旦改变，指纹也会改变，因此可以用来发现损坏的下载。 |
| **签名（Ed25519）** | 证明文件确实由其真正作者发布的方法。 |
| **APK** | Android 应用的文件格式。 |
| **MOTD** | “每日消息”：登录时显示的文字。 |
| **钩子（Hook）** | Kyanite 的一条小规则，用于在安装后配置软件包。参见[包钩子](package-hooks.md)。 |
| **基础系统（Base）** | Kyanite 预装的部分，通过 Kyanite 发布版更新，而不是作为普通软件包更新。 |
