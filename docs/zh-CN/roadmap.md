# 路线图与调研

本页概述了可能的未来工作方向。它不是固定的发布计划：随着开发和测试揭示出最有用的方向，优先级可能会改变。

## 用户体验

- 继续改进 Brush 的默认配置和登录体验。
- 改进 init 的日志，让启动和运行问题更容易诊断。
- 审查默认的 MOTD 和 shell 配置。
- 考虑添加目前基础系统中没有、但人们通常期望的常用工具。
- 探索回收站功能和云备份方案。

## 软件包兼容性

- 扩大对常用软件的测试，找出需要额外钩子的软件包。
- 继续测试开发工具和命令行应用。
- 调查应用检测到或假定了不同 Linux 环境时出现的兼容性问题。
- 研究其他 shell 如何与 Kyanite 的 init 和登录流程交互。

## 平台支持与稳定性

- 继续调查 QEMU 的启动和终端处理。
- 在更多环境中测试 rootfs，包括 `proot-distro` 和 udocker。
- 改善 `proot-distro` 的安装体验。
- 继续测试 x86_64 环境和其他宿主配置。
- 探索与内核相关的工作，以及其他启动或部署方式。

## 安全与维护

- 审查根文件系统中附带的文件。
- 继续审查包管理器的安全行为和软件源的版本选择。
- 调研用 Rust 实现替换剩余的 GNU `env` 组件。
- 审视静态 musl 二进制文件与动态链接组件之间的平衡。

## 体积与依赖

- 审查 Brush 和 uutils coreutils 等内置组件的体积和资源占用。
- 探索是否值得采用更小的替代品或针对性的优化。

## 其他想法

有些想法还处于探索阶段，可能不会成为 Kyanite 的一部分：

- X11 支持
- 额外的内核和设备工作流
- 使用 Kyanite 相关工具构建的、独立的、以安全为重点的发行版

项目 README 描述了当前面向用户的功能。本页记录的是正在考虑的方向，而不是承诺或发布计划。
